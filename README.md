🚀 New Portfolio

A modern, responsive personal portfolio website built with React and Vite — showcasing my projects, skills, and experience as a MERN Stack Developer.

🔗 Live Demo: new-portfolio-xi-two-11.vercel.app

📌 About

This is my personal portfolio website designed with a fresh theme to highlight my work as a MERN Stack Developer. It includes an animated introduction, project showcase, skills overview, and a working contact form.

✨ Features
🎨 Clean and responsive UI built with Bootstrap
⌨️ Animated typewriter text effect for dynamic introductions
📱 Fully responsive across desktop, tablet, and mobile devices
🧭 Smooth client-side navigation using React Router
📧 Functional contact form powered by EmailJS
⚡ Fast build and development experience with Vite
🛠️ Tech Stack

Frontend:

React 19
React Router DOM
Bootstrap 5
React Icons
Typewriter Effect

Tools & Services:

Vite (build tool)
EmailJS (contact form email delivery)
ESLint (code linting)
